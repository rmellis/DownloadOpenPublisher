WINDOWS ICO RESOLUTION ARCHITECTURE:
Windows .ico containers natively support embedding multiple resolution frames into
a single file. The standard maximum size for Windows icons is 256x256 pixels, which
uses PNG compression to retain full 32-bit alpha transparency while minimizing file
size.

1. Master Multi-Resolution .ico Files:
   Generated directly in the icons/ directory:
   - OpenPublisherv5Icon.ico (10 frames embedded, ~101 KB)
   - opubDocument.ico (10 frames embedded, ~130 KB)
   - Publication-icon-32x42.ico (10 frames embedded, ~102 KB)
   - openoublisherv5st-icon.ico (10 frames embedded, ~53 KB)

   Each master .ico contains the complete Windows standard resolution hierarchy:
   - 16x16: Taskbar, notifications, small list view (100% DPI)
   - 20x20: High-DPI 125% scaling for 16x16
   - 24x24: High-DPI 150% scaling for 16x16 / small taskbar
   - 32x32: Standard desktop icon, File Explorer tiles (100% DPI)
   - 40x40: High-DPI 125% scaling for 32x32
   - 48x48: Medium icons, dialog boxes, Control Panel (100% DPI)
   - 64x64: High-DPI 200% scaling for 32x32 / extra-large icon
   - 96x96: High-DPI 200% scaling for 48x48
   - 128x128: Jumbo icon
   - 256x256: Maximum standard Windows icon size (Vista, Win 7, 8, 10, 11)

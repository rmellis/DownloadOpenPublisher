Canvas Element Copy, Cut & Paste Subsystem Update

Overview:
Resolved an issue where copying and pasting canvas elements (such as Text Boxes, Shapes, and Tables) failed in the desktop application wrapper despite working in the web browser version.
This update introduces intelligent element-aware copy, cut, and paste across all input channels (keyboard shortcuts, ribbon toolbar buttons, right-click context menu, and application menubar/native bridge), while strictly preserving 100% fidelity for rich text, RTF, Discord styling, fonts, and colors when pasting into active text editors and table cells.

Key Fixes & Architectural Improvements:
1. Precise UI Button Target Matching:
   - Replaced container ancestor walking with targeted button resolution using closest('button, [role="button"], [role="menuitem"], .tool-btn, .btn, .pub-context-item, .context-item, .context-menu-item, .dropdown-item, ...').
   - Eliminates false positives where clicking other buttons (e.g. Copy) inside a ribbon group or toolbar was mistakenly intercepted by the container's concatenated text.

2. Intelligent Context Discrimination (Text Editing vs. Canvas Element):
   - Implemented reliable detection using isTextEditing() checking document.activeElement (including isContentEditable, INPUT, TEXTAREA, and closest('[contenteditable="true"]')).
   - Active Text Editing (Typing in a Text Box or Table Cell):
     - When pasting inside a text box or table cell, requests are routed to OP_GET_CLEAN_CLIPBOARD (webview.paste()).
     - Preserves full rich clipboard data (RTF, HTML formatting, Discord styles, background colors, custom fonts).
     - Does not duplicate or clone the parent canvas element.
   - Canvas Element Selected (Not editing text):
     - When a canvas element is selected, routes directly to window.pasteEl(inPlace).
     - Clones and appends the element to the canvas with the standard +20px offset (or 0px offset for "Paste in Place").
     - Updates selection to the newly pasted clone.

3. Universal Keyboard Shortcut Interception:
   - Added a top-level capture-phase keydown accelerator handler inside the guest world for Ctrl+C, Ctrl+X, and Ctrl+V (and Cmd+C, Cmd+X, Cmd+V on macOS).
   - Ctrl+C / Cmd+C:
     - If text is selected while typing, lets native browser text copy proceed untouched.
     - If canvas element(s) are selected, triggers window.copyEl() and synchronizes state.copiedElements.
   - Ctrl+X / Cmd+X:
     - If text is selected while typing, lets native browser text cut proceed untouched.
     - If canvas element(s) are selected, triggers window.cutEl() to remove from canvas and store in clipboard buffer.
   - Ctrl+V / Cmd+V:
     - If actively typing in a text box or table cell, allows native rich paste to proceed.
     - If not editing text and element buffer is present, intercepts and calls window.pasteEl(shiftKey).

4. Right-Click Context Menu Hooking:
   - Updated ContextMenuActions.pasteNormal hook inside wrapper.html.
   - Checks !isTextEditing && hasCopiedElements and invokes window.pasteEl(!!inPlace) for both standard and in-place pastes.
   - If editing text, routes to OP_GET_CLEAN_CLIPBOARD to preserve rich text paste in text boxes and table cells.

5. Application Menubar & Native Command Bridge:
   - Updated setupApplicationMenuBar() Edit menu items (Cut, Copy, Paste).
   - Updated handleNativeMenuCommand() cases 203 (Cut), 204 (Copy), and 205 (Paste).
   - Evaluates active editing state and element buffer dynamically rather than executing raw document.execCommand('paste'), which is blocked in modern Chromium environments.

6. Webview Permissions:
   - Added clipboardRead and clipboard-sanitized-write to the webview permissionrequest listener in wrapper.html, ensuring uninterrupted clipboard operations.

Testing & Verification:
- Verified with automated test suite covering:
  - Keyboard Ctrl+C and Ctrl+V on canvas text boxes (verified +20px offset).
  - Ribbon Copy and Ribbon Paste buttons.
  - Context menu 'Paste' and 'Paste in Place'.
  - Active text box editing paste (verified OP_GET_CLEAN_CLIPBOARD routing and zero element duplication).
  - Active table cell editing paste (verified OP_GET_CLEAN_CLIPBOARD routing and zero element duplication).
  - All 15 assertion checks passed with 100% success.

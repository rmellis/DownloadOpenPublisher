User Guide & Documentation

Everything you need to master Open Publisher v4 and above

🖥️ Interface Overview

Inspired by classic productivity suites, the layout is instantly familiar:

  • Title Bar: Rename documents, Undo/Redo, and view exact mouse coordinates.
  • Ribbon Menu: Houses all tools. Contextual tabs appear automatically for specific items.
  • Sidebar: Manage, add, or delete your pages.
  • Canvas & Rulers: Hardware-accelerated rulers measure in true CM/MM, tracking physical dimensions.
  • Zoom Controls: Scale the canvas gracefully from 60% to 150%.

📂 File Management

Save natively or export to PDF. You can open files via the menu, or drag-and-drop onto the canvas.

  • .opub Files: Your master working file.
  • Legacy Support: Experimental import for .pub files.
  • Word Docs (.docx): Import as Editable Text or as a Flattened Image for strict layout preservation.

✏️ Core Editing

  • Selection: Click to select, or drag a Marquee box to multi-select.
  • Grouping: Right-click multiple items and select Group.
  • Transform: Drag to move, use white handles to resize, or drag past an edge to mirror/flip objects.
  • Context Menus: Right-click anything for rapid layer arrangements and formatting.

📝 Working with Text

Insert Text Boxes and format them via the floating toolbar.

  • Text Fit: Right-click > Best Fit to auto-scale font.
  • Drop Cap: Stylize the first letter of paragraphs.

Use WordArt to access 200 pre-styled headline graphical effects.

🖼️ Images & Graphics

When an image is selected, the contextual Picture Tools tab appears:

  • Crop to Shape: Instantly cut your photo into circles, stars, or triangles.
  • Filters: Apply grayscale, sepia, color tints, or drop-shadows instantly.
  • Assets: Use built-in Clipart, Shapes, and Ad Stickers.

📏 Layout & Printing

Control the look of the paper via the Page Design tab.

  • Page Setup: Toggles for Margins, Size, and Orientation.
  • Fancy Borders: Apply Art Deco, Floral, or Certificate borders to the edge.

Perfect Printing

  • Zero Spillage: Mathematical zoom-box ensures no accidental blank trailing pages.
  • Color Accuracy: Halos and backgrounds print exactly as seen on screen.

📄 Pages & Templates

Manage pages via the left sidebar. Add, delete, and manage unique Headers & Footers per page.

Go to File > Templates to browse Resumes, Flyers, and Menus.

📝 Note: Loading a template replaces the content of your currently selected page.

🗂️ Ribbon Reference

🏠 Home Tab

PDF Export, Clipboard, Font styling, Select All, and Layer Arrangement.

➕ Insert Tab

Text Boxes, Pictures, Clipart, Shapes, WordArt, Stickers, and Tables.

🎨 Page Design Tab

Margins, Orientation, Fancy Borders, Headers/Footers, and Background Themes.
